# Before · after · reference

Every screen of the Kindling console before the upgrade (`ui`, `19e7830`) and after it (`ui-upgrade`).

- **Size:** 1440 wide; drawers are shown in a 1440×1800 viewport.
- **Sources:** screenshots come from `npm run design:capture`; references are details.so entries (patterns only, see DESIGN.md §2).
- **Local frames:** reference frames are kept locally in `refs/` and gitignored (third-party; public repo).
- **Videos:** `videos/01-change-as-of.webm`, `videos/02-open-drawer.webm`, `videos/03-load-backtest.webm`.
